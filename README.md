# Zombie BreakIn 3D

A lightweight 3D survival-horror vertical slice using Three.js, Vite and Capacitor.

## Chrome
Run:
`npm install`
`npm run dev`

Or use a static server for the built `dist/` folder.

## APK
Push the project to a GitHub repository and run **Build Zombie BreakIn APK** from Actions. The workflow creates a debug APK artifact.

The APK is not signed for Play Store release; it is intended for testing/sideloading.
